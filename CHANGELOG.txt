File: ppfas_downloader.py
Problem: The script was hard-coded to only download files strictly for the year "2025". This meant it would permanently stop working once 2026 arrived.
Change Made: Rewrote the logic. It now automatically detects the current year and downloads those files. It also checks the previous year so it never misses a month (like December's data arriving in January). Folders also changed from targeting "2025" to a general "PPFAS_Disclosures" folder.

File: aggregate_portfolio.py
Problem 1: It was hard-coded to combine files only if they were sitting inside the "2025" folder.
Change Made 1: Updated the code to read all data from the new, future-proof "PPFAS_Disclosures" folder instead.
Problem 2: The script crashed completely when reading new AMC files (like "March_2026.xls") because the mutual fund house slightly changed how their Excel files were formatted internally.
Change Made 2: Added a backup reading method. If the first try fails, the script seamlessly switches to an 'openpyxl' system which fixes the crash and extracts the data perfectly.

File: .github/workflows/update_data.yml
Problem: You previously had to run the scripts manually, but you wanted the database to reliably update itself every single day exactly at 5:00 AM IST.
Change Made: Created a brand new GitHub Actions command file. It commands the GitHub servers to automatically wake up, run the scripts independently, and push the updated master Excel file live automatically at precisely 5:00 AM IST.

File: .gitignore
Problem: The thousands of raw monthly Excel files being downloaded could accidentally upload to the website and bloat the storage size.
Change Made: Updated the ignore list to hide the newly named "PPFAS_Disclosures" folder from the online repository completely, keeping your project clean.
